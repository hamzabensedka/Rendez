# Progress Report
## Introduction
The Planity Clone project aims to connect users with local businesses, allowing them to discover, book, and manage appointments.
## Completion Status
The current completion percentage of the project is 60%.
## Remaining Scope
The following features are still open:
* Payment: The payment gateway integration is pending.
* Provider Portal: The provider portal for businesses to manage their listings and appointments is not yet implemented.
* Reviews: The review and rating system for users to leave feedback about businesses is still missing.
* Notifications: The notification system for appointment reminders, booking confirmations, and other important events is not yet integrated.
* Admin: The admin dashboard for managing the app, including business listings, user accounts, and analytics, is still under development.
* BullMQ: The background jobs for handling tasks such as sending notifications and computing availability are not yet implemented.
* User Profile: The user profile management feature is partially implemented, but still requires some work.
